# PAYO Backend Testing APIs

## Base URL

```txt
http://payo-app.duckdns.org:3001
 ```

---

# AUTH APIs

---

## 1. Send Registration OTP

### URL

```txt
 POST http://payo-app.duckdns.org:3001/api/auth/send-otp
 ```

### Token Required

❌ No

### Body

```json
 {
 "mobile": "9876543210"
 }
 ```

---

## 2. Verify Registration OTP

### URL

```txt
 POST http://payo-app.duckdns.org:3001/api/auth/verify-otp
 ```

### Token Required

❌ No

### Body

```json
 {
 "mobile": "9876543210",
 "otp": "1234"
 }
 ```

### Response

Returns JWT token.

---

## 4. Register User

### URL

```txt
 POST http://payo-app.duckdns.org:3001/api/auth/register
 ```

### Token Required

✅ Yes

### Headers

```txt
 Authorization: Bearer YOUR_VERIFY_OTP_TOKEN
 ```

### Body

```json
 {
 "name": "user",
 "email": "user@gmail.com",
 "password": "Password@123",
 "confirmpassword": "Password@123",
 "referralCode": "PAYO123"
 }
 ```

---
