Here are all the Admin APIs to test:

---

## 1 — Admin Login
**Method:** `POST`
**URL:** `http://localhost:3001/api/admin/auth/login`
**Body:**
```json
{
  "email": "admin@payo.com",
  "password": "Admin@123"
}
```

---

## 2 — Create Sub Admin
**Method:** `POST`
**URL:** `http://localhost:3001/api/admin/auth/create-admin`
**Headers:** `Authorization: Bearer <super_admin_token>`
**Body:**
```json
{
  "name": "Admin One",
  "mobile": "9111111111",
  "email": "admin1@payo.com",
  "password": "Admin@123"
}
```

---

## 3 — Get All Admins
**Method:** `GET`
**URL:** `http://localhost:3001/api/admin/auth/all-admins`
**Headers:** `Authorization: Bearer <super_admin_token>`

---

## 4 — Revoke Admin Access
**Method:** `PATCH`
**URL:** `http://localhost:3001/api/admin/auth/revoke-admin/:adminId`
**Headers:** `Authorization: Bearer <super_admin_token>`

---

## 5 — Change Admin Password
**Method:** `PATCH`
**URL:** `http://localhost:3001/api/admin/auth/change-password`
**Headers:** `Authorization: Bearer <admin_token>`
**Body:**
```json
{
  "currentPassword": "Admin@123",
  "newPassword": "Admin@456"
}
```
