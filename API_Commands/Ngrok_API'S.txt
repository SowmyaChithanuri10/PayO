# PayO Admin APIs (ngrok URLs)

## Base URL

```text
https://anemia-stove-chief.ngrok-free.dev
```

---

# 1 — Admin Login

**Method:** `POST`

**URL:**

```text
https://anemia-stove-chief.ngrok-free.dev/api/admin/auth/login
```

**Body:**

```json
{
  "email": "admin@payo.com",
  "password": "Admin@123"
}
```

---

# 2 — Create Sub Admin

**Method:** `POST`

**URL:**

```text
https://anemia-stove-chief.ngrok-free.dev/api/admin/auth/create-admin
```

**Headers:**

```text
Authorization: Bearer <super_admin_token>
```

**Body:**

```json
{
  "name": "Admin One",
  "mobile": "9111111111",
  "email": "admin1@payo.com",
  "password": "Admin@123"
}
```

#2.1 - getAllUsers` API URL is:

```bash
GET /api/admin/auth/users
```

Full localhost example:

```bash
https://anemia-stove-chief.ngrok-free.dev/api/admin/auth/users
```

This route is protected, so send:

### Headers

```js
Authorization: Bearer YOUR_ADMIN_TOKEN
```

Example in frontend:

```js
axios.get("https://anemia-stove-chief.ngrok-free.dev/api/admin/auth/users", {
  headers: {
    Authorization: `Bearer ${token}`
  }
})
```
